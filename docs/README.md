# Quell 文档说明

Quell 是一个B站缓存视频合并工具。

## 项目定位

1. 支持本地缓存合并。
2. 支持远程下载。

## 使用说明

1. 本地模式用于合并你设备上的缓存文件。
2. 远程下载用于按需获取视频内容。
3. 使用时请留意平台规则。
