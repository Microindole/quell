# Quell Documentation

Quell is a Bilibili cache video merge tool.

## Project Positioning

1. Supports local cache merge.
2. Supports remote download.

## Usage Notes

1. Local mode merges cache files on your device.
2. Remote download can fetch video content when needed.
3. Please be aware of platform rules when using these features.
