# 快速开始

本指南将带您完成 Quell 的配置与核心功能探索。

## 第一步：获取 Quell

您可以根据您的需求选择最适合的版本：

*   **Standard (标准版)**: 体积小巧，依赖于系统安装的 FFmpeg。如果您已有 FFmpeg 环境，请选此版。
*   **Bundled (内置版)**: 包含经过优化的 FFmpeg，无需手动配置环境。**推荐新手下载。**

前往 [GitHub Releases](https://github.com/Microindole/quell/releases) 下载对应平台的二进制文件。

---

## 第二步：核心功能预览

### 1. 登录与认证
Quell 支持通过扫描二维码快速登录 B 站，解锁 1080P/4K 等最高画质。

![扫码登录 B 站](/assets/扫码登录B站.png)

### 2. 远程视频搜索
您可以输入关键词快速搜索 UP 主或特定视频，支持按 UID 精准定位。

![搜索 UP 主](/assets/远程视频下载-搜索up主.png)
![通过 UID 搜索](/assets/远程视频下载-UID.png)

### 3. 本地缓存管理
自动扫描本地 B 站客户端的缓存目录，并进行智能聚合展示。

![本地缓存视频查看](/assets/本地缓存视频查看.png)

### 4. 智能合并导出
一键将下载或扫描到的音视频分片合并为完整的 MP4 或 MKV 文件。

![合并缓存视频](/assets/合并缓存视频.png)

### 5. 动态追踪与日志
根据时间线精准定位 UP 主动态，并实时记录运行日志。

![根据时间查找动态](/assets/根据时间查找动态.png)
![日志查看](/assets/日志查看.png)

## 第三步：运行与操作

### TUI 模式 (默认)
直接运行程序即可进入终端交互模式。适合追求效率的极客。
```bash
./quell
```

### GUI 模式
在运行程序时附加 `-gui` 参数，即可进入图形界面模式。适合批量管理与扫码登录。
```bash
./quell -gui
```
