# Quell 下载器功能完善计划

## 当前状态

已完成 BBDown 替代的最小可用版本，支持根据 BVID 下载视频（自动选最高可用画质 + ffmpeg 合并）。
未登录状态下最高只能获取 480P 画质。

## 待实现功能（按优先级排序）

### P0 - 核心体验

- [ ] **Cookie 登录支持**
  - 支持通过配置文件传入 SESSDATA Cookie
  - 解锁 1080P / 4K / HDR 画质
  - 在 `GetPlayURL` 和 `GetVideoInfo` 请求中附带 Cookie
  - 配置项: `config.Cookie` 字段

- [ ] **分P视频支持**
  - 获取视频所有分P的 CID 列表
  - 支持选择下载单P或全部P
  - 文件名带分P序号和标题

### P1 - 下载体验

- [ ] **多线程下载**
  - HTTP Range 分段并行下载
  - 可配置并发数（默认 4 线程）
  - 提升大文件下载速度

- [ ] **断点续传**
  - 下载中断后可从上次位置继续
  - 临时文件 + 进度记录

- [ ] **下载进度条**
  - 在 TUI 中实时显示下载百分比和速度
  - 替代当前的简单文字状态

### P2 - 功能扩展

- [ ] **画质/编码选择**
  - 列出所有可用画质供用户选择
  - 支持 AVC / HEVC / AV1 编码偏好

- [ ] **批量下载**
  - 在远程列表中支持多选
  - 队列式逐个下载

- [ ] **弹幕下载**
  - 下载 XML 弹幕文件
  - 可选转为 ASS 字幕格式

- [ ] **字幕下载**
  - 获取 CC 字幕（如果有的话）

### P3 - 更多来源

- [ ] **番剧/电影支持**
  - 支持 EP 号解析
  - 番剧专用 API 调用

- [ ] **收藏夹/合集批量下载**
  - 支持按收藏夹 ID 批量获取
  - 支持按合集/系列批量获取

- [ ] **自定义文件名模板**
  - 支持 `{title}`, `{bvid}`, `{author}` 等变量
