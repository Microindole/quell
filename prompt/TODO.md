# Quell 下载器功能完善计划

## 当前状态

已完成 BBDown 替代的最小可用版本，支持根据 BVID 下载视频（自动选最高可用画质 + ffmpeg 合并）。
未登录状态下最高只能获取 480P 画质。

## 待实现功能（按优先级排序）

### P0 - 核心体验

- [x] **Cookie 登录支持**
  - SESSDATA 通过配置文件传入，GUI/TUI 启动时均自动生效
  - 解锁 1080P / 4K 画质
  - 进展（2026-03-03）: GUI 已支持“扫码登录”并自动回填/保存 SESSDATA

- [x] **分P视频支持**
  - GUI: 下载前弹窗选择分P，支持全选；单分P直接下载
  - TUI: 下载全部分P

### P1 - 下载体验

- [x] **多线程下载**
  - HTTP Range 分段并行下载（4 线程）
  - 文件大小 < 2MB 或服务器不支持 Range 时自动回退到单线程

- [x] **断点续传**
  - 下载中断后可从上次位置继续
  - 临时文件 + 进度记录

- [x] **下载进度条**
  - 在 TUI 中实时显示下载百分比和速度
  - 替代当前的简单文字状态
  - 进展（2026-03-03）: 远程下载改为优先保存到 output_dir；合并时尝试嵌入原视频封面（失败自动回退）

### P1.5 - 本地合并引擎（已完成）

- [x] **CI/CD 与自动化打包**
  - 集成 GitHub Actions 自动发布 Release
  - 支持 `standard` 和 `bundled` (内置 FFmpeg) 双版本构建
  - 实现内置 FFmpeg 的自动释放与路径引导

- [x] **移除 PowerShell 依赖**
  - `engine/merge.go` 完全用纯 Go 重写
  - `stripBiliHeader()`: 扫描前 256 字节找 ftyp 魔数，跳过 B站私有头部
  - `findM4SPairs()`: 解析两种命名格式，quality ≥ 30200 = 音频，< 30200 = 视频
  - 多分P自动输出 `_p1`, `_p2` 后缀文件

- [x] **GUI 封面图显示**
  - `ScanVideos()` 读取 `image.jpg` / `group.jpg` 转 base64 data URL
  - 规避 WebView2 不允许从 `http://wails.localhost` 访问 `file://` 路径的限制

- [x] **导出格式选择**
  - 配置项 `output_format`（`mp4` / `mkv`）
  - 设置页新增下拉选择器

- [x] **扫描深度不足**
  - 实现递归扫描，适配 `BiliDir/[bvid]/[cid]/[quality]/video.m4s` 嵌套结构

- [x] **`.m4s` 文件名正则不覆盖新格式**
  - 兼容 `video.m4s` / `audio.m4s` 直接名称格式，并从父目录解析画质

- [x] **已合并状态不持久**
  - 扫描时自动检查导出目录，存在对应文件则标记为“完成”并记录路径

- [x] **输出目录支持自定义**
  - 新增 `output_dir` 配置，支持将视频导出到独立目录，避免被 B 站客户端清理

- [x] **合并进度反馈**
  - 解析 FFmpeg stderr 的 `time=` 字段，实时将进度推送至 GUI 状态栏

- [x] **合并成功后增加快捷操作**
  - 增加“播放视频”按钮，支持直接打开合并后的文件

- [x] **批量合并支持**
  - GUI 增加“全部合并”按钮，支持一键处理队列任务

### P2 - 功能扩展

- [x] **远程视频列表分页体验优化**
  - 当前分页交互体验较差（翻页效率低、定位成本高）
  - 优化分页控件与页跳转能力（如页码跳转、每页数量、快速翻页）
  - 进展（2026-03-03）: GUI 已支持首页/尾页/跳页/每页数量（20/30/50）

- [x] **画质/编码选择**
  - 列出所有可用画质供用户选择
  - 支持 AVC / HEVC / AV1 编码偏好
  - 进展（2026-03-03）: GUI 下载弹窗已支持画质与编码下拉选择，后端已支持按偏好选流并自动回退

- [x] **批量下载**
  - 在远程列表中支持多选
  - 队列式逐个下载
  - 进展（2026-03-03）: GUI 远程列表支持多选与队列顺序下载（默认最高可用）

- [ ] **弹幕下载**
  - 下载 XML 弹幕文件
  - 可选转为 ASS 字幕格式

- [ ] **字幕下载**
  - 获取 CC 字幕（如果有的话）

- [ ] **UP主动态浏览与历史定位**
  - 支持抓取/浏览 UP 主动态列表
  - 支持快速定位较早时期动态（避免无限下翻）
  - 支持下载历史动态中的图片资源
  - 待完善：动态正文富文本节点渲染细节（`@` / 话题 / 表情 / 链接样式区分）与长文展开/收起交互

- [x] **本地扫描兼容远程下载结果**
  - 本地视频分页扫描需覆盖远程下载产物
  - 通过扫描到的本地 B站缓存结果判定来源，不引入额外 sidecar 标记文件
  - 进展（2026-03-03）: 已移除 `.quell.json` 机制；仅当未命中对应本地缓存任务时标记“无本地缓存”

### P3 - 更多来源

- [ ] **番剧/电影支持**
  - 支持 EP 号解析
  - 番剧专用 API 调用

- [ ] **收藏夹/合集批量下载**
  - 支持按收藏夹 ID 批量获取
  - 支持按合集/系列批量获取

- [ ] **自定义文件名模板**
  - 支持 `{title}`, `{bvid}`, `{author}` 等变量
