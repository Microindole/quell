# Quell 下载器功能完善计划

## 当前状态

已完成 BBDown 替代的最小可用版本，支持根据 BVID 下载视频（自动选最高可用画质 + ffmpeg 合并）。
未登录状态下最高只能获取 480P 画质。

## 待实现功能（按优先级排序）

### P0 - 核心体验

- [x] **Cookie 登录支持**
  - SESSDATA 通过配置文件传入，GUI/TUI 启动时均自动生效
  - 解锁 1080P / 4K 画质

- [x] **分P视频支持**
  - GUI: 下载前弹窗选择分P，支持全选；单分P直接下载
  - TUI: 下载全部分P

### P1 - 下载体验

- [x] **多线程下载**
  - HTTP Range 分段并行下载（4 线程）
  - 文件大小 < 2MB 或服务器不支持 Range 时自动回退到单线程

- [ ] **断点续传**
  - 下载中断后可从上次位置继续
  - 临时文件 + 进度记录

- [ ] **下载进度条**
  - 在 TUI 中实时显示下载百分比和速度
  - 替代当前的简单文字状态

### P1.5 - 本地合并引擎（已完成主体）

- [x] **移除 PowerShell 依赖**
  - `engine/merge.go` 完全用纯 Go 重写
  - `stripBiliHeader()`: 扫描前 256 字节找 ftyp 魔数，跳过 B站私有头部
  - `findM4SPairs()`: 解析两种命名格式，quality ≥ 30200 = 音频，< 30200 = 视频
  - 多分P自动输出 `_p1`, `_p2` 后缀文件

- [x] **GUI 封面图显示**
  - `ScanVideos()` 读取 `image.jpg` / `group.jpg` 转 base64 data URL
  - 规避 WebView2 不允许从 `http://wails.localhost` 访问 `file://` 路径的限制

- [x] **导出格式选择**
  - 配置项 `output_format`（`mp4` / `mkv`）
  - 设置页新增下拉选择器

- [ ] **扫描深度不足（可能导致完全找不到文件）**
  - 当前 `scanner.go` 只扫 `BiliDir/` 一级子目录，`findM4SPairs` 也只在 `task.Dir` 直接目录查找
  - 新版B站PC客户端实际结构为 `BiliDir/[bvid]/[cid]/[quality]/video.m4s`，嵌套多层
  - 需要递归扫描或适配嵌套结构

- [ ] **`.m4s` 文件名正则不覆盖新格式**
  - `parseM4SName` 只认 `[id]_p1-1-30280.m4s` 命名，新版客户端可能直接叫 `video.m4s` / `audio.m4s`
  - 需要兼容"直接名称"格式（位于子目录中时根据文件名判断视频/音频）

- [ ] **已合并状态不持久**
  - 每次刷新列表，所有卡片状态归零为"等待"
  - 应在扫描时检查对应 `.mp4` / `.mkv` 是否已存在，自动标记"已导出"

- [ ] **输出目录写回缓存目录**
  - 合并结果 `outPath := filepath.Join(task.Dir, ...)` 直接写在B站缓存目录里
  - B站清理缓存时会连带删除；应支持配置独立输出目录

- [ ] **合并进度反馈**
  - 合并期间无进度显示，仅有"处理中"状态，FFmpeg 跑几分钟界面无反馈
  - 可解析 FFmpeg stderr（`time=` 字段）实时推送进度事件到状态栏

- [ ] **合并成功后缺少"打开文件"快捷操作**
  - 当前只有"打开文件夹"，合并完需自己找文件
  - 可在 done 事件后将输出路径存到 task，显示"打开文件"按钮

- [ ] **无批量合并**
  - 只能逐个点击，应在页面 header 加"全部合并"按钮

### P2 - 功能扩展

- [ ] **画质/编码选择**
  - 列出所有可用画质供用户选择
  - 支持 AVC / HEVC / AV1 编码偏好

- [ ] **批量下载**
  - 在远程列表中支持多选
  - 队列式逐个下载

- [ ] **弹幕下载**
  - 下载 XML 弹幕文件
  - 可选转为 ASS 字幕格式

- [ ] **字幕下载**
  - 获取 CC 字幕（如果有的话）

### P3 - 更多来源

- [ ] **番剧/电影支持**
  - 支持 EP 号解析
  - 番剧专用 API 调用

- [ ] **收藏夹/合集批量下载**
  - 支持按收藏夹 ID 批量获取
  - 支持按合集/系列批量获取

- [ ] **自定义文件名模板**
  - 支持 `{title}`, `{bvid}`, `{author}` 等变量
