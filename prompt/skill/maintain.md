# Agent 维护技能 (Maintenance Skill)

## 目标
确保 `prompt/` 目录下的所有内容（包括项目上下文、任务清单、技能说明等）能够真实、实时地反映项目现状。

## 更新触发时机
Agent 在执行以下操作后，应自动更新 `prompt/` 目录内容：
1. **完成一个重大功能**: 更新 `context.md` 中的功能描述。
2. **修改项目结构**: 更新 `context.md` 中的目录树说明。
3. **变更依赖**: 更新 `context.md` 中的技术栈或依赖说明。
4. **配置文件变更**: 同步 `context.md` 中关于配置文件的说明。
5. **对话结束或阶段性总结**: 将 Antigravity 的内部 `task.md`、`implementation_plan.md` 和 `walkthrough.md` 同步到 `prompt/` 目录。

## 更新要求
- **及时性**: 任务完成后立即更新，不要堆积。
- **准确性**: 描述必须与代码实现或实际配置完全一致。
- **简洁性**: 保持文档精炼，避免冗余。
